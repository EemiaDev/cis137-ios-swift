# Aimee's Oahu Diary

A SwiftUI iOS app that turns my 4-day Oahu itinerary into a digital travel diary.

## How to Use the App

1. Open the app to see the itinerary list.
2. Tap any day to open its page and read about that part of the trip.
4. Tap return button in the top left corner to return to the list.
